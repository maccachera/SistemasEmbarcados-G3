Como o dispositivo se comunica

  1. O ESP32 entra na mesma rede Wi-Fi deste computador.
  2. Consulta sua programação usando o código do dispositivo.
  3. Armazena os horários localmente e usa o RTC DS3231.
  4. Envia os eventos de volta para o histórico.
